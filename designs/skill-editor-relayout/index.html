Step 2 of 4 · Appearance

A · Top tabs familiar

  • + Most literal "horizontal"; zero learning curve
  • + Tab dots/counts surface per-category status
  • ~ Tabs get cramped if categories grow past ~5
  • ~ One category visible at a time

B · Side rail scalable

  • + All categories + status visible at once
  • + Room for icons, sublabels, badges; scales cleanly
  • + Matches IDE / settings mental model
  • ~ Widest footprint (three columns)

C · Stepper onboarding

  • + Best for first-time creation; clear progress
  • + Reduces blank-page overwhelm
  • ~ Heavier for quick edits to one field
  • ~ Implies linear order that editing doesn't need
